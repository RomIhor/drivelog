Export to Excel
Downloads a CSV file with all pending trips. On your PC, open your XLSM file and run the ImportTrips macro — it will paste the new rows automatically.
How to set up the macro
1
In your XLSM file, press Alt+F11 to open the VBA editor
2
Insert → Module, then paste the macro code from the macro.bas file (download below)
3
Save as .xlsm. Run ImportTrips after each CSV export
